## 📚 How to Get Started

### 1. Review Structure
```bash
cd TILAWA
ls -la
# See organized project structure
```

### 2. Read Documentation
- Start with: `README.md` (project overview)
- Then: `PROJECT_SUMMARY.md` (detailed status)
- Quick Help: `QUICK_REFERENCE.md` (commands)

### 3. Setup Development
```bash
# Follow QUICK_REFERENCE.md
# Terminal 1: Backend
cd apps/backend/server && npm run dev

# Terminal 2: Frontend
cd apps/web/frontend && npm run dev

# Terminal 3: Mobile
cd apps/mobile/tilawa && flutter run
```

### 4. Deploy
- Web: Follow `docs/deployment/DEPLOYMENT.md`
- Mobile: Follow `docs/deployment/MOBILE_DEPLOYMENT.md`

### 5. Contribute
- Read: `CONTRIBUTING.md`
- Fork repository
- Create feature branch
