DEPLOYMENT STEPS
================================================================================

FOR LOCAL TESTING (5-10 minutes):

  1. Create database:
     createdb tilawa_dev

  2. Apply schema:
     psql -U postgres -d tilawa_dev < database/schema.sql

  3. Start backend (Terminal 1):
     cd backend
     python -m venv venv
     venv\Scripts\activate
     pip install -r requirements.txt
     python -m uvicorn main:app --reload

  4. Start frontend (Terminal 2):
     cd frontend
     pnpm dev

  5. Access application:
     http://localhost:3000

FOR VERCEL DEPLOYMENT (30-45 minutes):

  1. Push to GitHub:
     git push

  2. Create Vercel project:
     • Sign in to Vercel
     • Select GitHub repository
     • Import project

  3. Add environment variables:
     • NEXT_PUBLIC_API_URL
     • NEXT_PUBLIC_BETTER_AUTH_URL
     • NEXT_PUBLIC_QURAN_API_BASE
     • DATABASE_URL (cloud PostgreSQL)
     • BETTER_AUTH_SECRET

  4. Deploy:
     • Click "Deploy"
     • Wait for build completion
     • Access at https://[project].vercel.app
